# Kadath
Алгоритмическая торговля биржевыми инструментами.

## Структура проекта

### model
Общие структуры данных, часто используемые типы, математические функции.

### db
Функции для работы с БД.

### experiment
Эксперименты с торговлей календарным спредом фьючерсов, сбор статистики.

### exp_single
Эксперименты с торговлей одним фьючерсом, сбор статистики.

### signal
Библиотека для вычисления торговых сигналов.

### signal_test
Бэктест.

### kadath
Приложение торгового робота.

### abstract_broker
Описание функций брокера.

### tinvest
Реализация abstract_broker для API Т-Инвестиции.

### alor
Реализация abstract_broker для API Алор.

### cleaner
Приложение для автоматической чистки исторических данных.

## Методы предсказаний

### Линейная функция с калибровкой методом Нелдера-Мида
Не показывала положительный результат на реальных данных.

### Предсказание Ядра
Использовалось совместно с линейной функцией для увеличения надёжности предсказаний, однако достаточную надёжность не показало.

### Gradient Boosting
Не показывает устойчивый положительный результат на реальных данных.
